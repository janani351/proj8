# Calculator

A responsive, browser-based mini project built with **HTML, CSS and vanilla JavaScript**.

## Run
1. Extract the ZIP file.
2. Open `index.html` in a modern browser.
3. No installation, server, or external library is required.

## Notes
- Data for Notes, Pomodoro session count, and Job Application Tracker is stored locally in your browser using `localStorage`.
- The Password Generator uses the browser's cryptographic random number generator when available.
- These are front-end demo projects. Local browser data stays in that browser and is not synced across devices.
